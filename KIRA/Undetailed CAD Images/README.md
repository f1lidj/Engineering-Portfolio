# KIRA — Preliminary CAD Views

These views provide limited visual context for the **KIRA long-endurance ISR / Counter-UAS preliminary aircraft design**.

## My Responsibility

As Team Leader, I coordinated the five-member design activity and the aircraft-level integration of configuration, mission systems, propulsion, performance, mass properties and preliminary structures. The CAD configuration was part of that multidisciplinary design process.

> **Public-material note:** KIRA contains non-public design work. Only intentionally simplified and shareable views are shown; detailed geometry, calculations and internal design data cannot be distributed publicly.
