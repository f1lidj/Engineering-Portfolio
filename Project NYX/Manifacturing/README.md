# NYX — Manufacturing & Integration

This section shows the physical build and integration phase of **Project NYX**, a fixed-wing UAV developed within Fly Mi – Politecnico di Milano.

## My Responsibility

As **Head of Electric Propulsion**, I was responsible for ensuring that the selected propulsion architecture could be integrated into the real aircraft. My work included motor and ESC installation constraints, battery placement, high-current wiring, connectors, cooling, maintainability and troubleshooting during assembly.

The manufacturing phase was where analytical sizing and component choices were converted into a flight-ready installed system.

> **Public-material note:** only selected shareable NYX material is included. Additional internal project data and documentation are not public.
