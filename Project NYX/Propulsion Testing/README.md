# NYX — Propulsion Testing

Experimental testing was used to validate the electric propulsion system for **Project NYX** before and during aircraft integration.

## My Responsibility

As **Head of Electric Propulsion**, I planned and coordinated propulsion validation activities covering:

- static thrust and electrical-performance testing;
- motor–propeller operating-point verification;
- battery and high-power hardware behaviour under load;
- wind-tunnel characterisation under representative incoming flow;
- comparison between analytical predictions and measured behaviour;
- identification and resolution of integration issues before flight.

The objective was to optimise the complete installed propulsion system rather than maximise a single static-performance metric.

> **Public-material note:** only selected shareable NYX testing material is included. Detailed test data and internal project documentation are not public.
