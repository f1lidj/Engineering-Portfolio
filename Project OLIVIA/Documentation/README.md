# O.L.I.V.I.A. — Engineering Documentation

O.L.I.V.I.A. was developed through a structured engineering process covering requirements, design reviews, verification, flight readiness and field operations.

## My Responsibility

As **Chief Technology Officer**, I coordinated the technical programme and contributed to the definition and maintenance of the engineering framework used to move the aircraft from design to flight.

My responsibilities included requirements flow-down, design-review coordination, readiness criteria, Test Hazard Analysis, flight procedures, checklists, anomaly tracking and the technical decision process supporting return-to-flight and competition readiness.

> **Public-material note:** the programme generated additional internal engineering documentation that is not public. This repository contains only material approved for public sharing.
