# O.L.I.V.I.A. — Flight Testing & Systems Integration

Flight testing was a central part of the O.L.I.V.I.A. development process, progressing from simulation and demonstrators to the competition aircraft.

## My Responsibility

As **Chief Technology Officer**, I planned and supervised the verification strategy and more than **150 hours of flight-test activity across three aircraft**.

My work covered test objectives and readiness gates, autonomous mission validation, GCS and communications integration, hardware troubleshooting, anomaly investigation, corrective actions and confirmation testing before return to flight.

The wider de-risking campaign also included extensive SITL/HITL and simulator activity before full-aircraft validation.

> **Public-material note:** only selected public test media is included. Detailed flight data, software, analyses and internal test documentation are not distributed.
