# O.L.I.V.I.A. — Manufacturing & Aircraft Integration

As **Chief Technology Officer**, I coordinated manufacturing and integration dependencies across structures, propulsion, electronics, control systems and mission equipment.

My work focused on aircraft-level technical decisions, interface management, build sequencing, procurement constraints, integration troubleshooting and verification of assembled systems, including the payload-release architecture.
