# Current Thrust-Stand Firmware

This is the current firmware branch for the **Arduino thrust and torque measurement system**.

## My Work

I integrated the main test-stand functions into a single operating workflow: dual-sensor acquisition, calibration and tare logic, local status display, physical controls, safety/status indication and serial interaction with the PC-side logger.

The objective was to make repeated propulsion tests faster, more consistent and less dependent on manual data handling.
