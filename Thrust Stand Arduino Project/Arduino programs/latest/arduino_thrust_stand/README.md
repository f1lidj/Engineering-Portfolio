# Integrated Arduino Test-Stand Controller

This firmware controls the current version of the **static thrust and torque test stand**.

## My Work

I implemented and refined the operating logic around dual HX711 load-cell acquisition, unit conversion, calibration, re-zeroing between tests, LCD feedback, button-based calibration, timed acquisition and bidirectional serial control.

The controller is designed to support repeatable test execution while providing both immediate local feedback and structured data acquisition on the PC.
