ARDUINO THRUST & TORQUE TEST STAND — ENGINEERING DOCUMENTATION

Project
-------
This project is an Arduino-based static propulsion test stand developed to acquire thrust and torque from load cells during repeatable bench tests.

My work
-------
I developed and adapted the measurement workflow, including dual-sensor acquisition, calibration and re-zeroing, LCD/user interaction, serial test control and integration with PC-side logging.

This section contains the supporting engineering information used to understand the hardware architecture, electrical connections and operating logic of the stand.

The documentation is intended as technical context for the experimental system, not as a duplicate of the implementation itself.
