# Thrust-Stand Experimental Data

This section contains example acquisitions produced during development and testing of the **Arduino thrust and torque stand**.

## My Work

I developed the acquisition workflow so that measured thrust and torque could be streamed from the embedded controller, captured on the PC and stored in a structured form for later analysis.

The data here demonstrates the end-to-end measurement chain from physical load cells through embedded processing and serial communication to recorded experimental results.
