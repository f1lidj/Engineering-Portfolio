# Arduino Thrust & Torque Test Stand

This project is an **instrumented static propulsion test stand** for simultaneous thrust and torque measurement, intended to support repeatable experimental testing of small propulsion systems.

## My Work

I developed and adapted the measurement and acquisition workflow around the stand, integrating:

- two load-cell channels through HX711 interfaces;
- thrust and torque calibration and automatic re-zeroing;
- local LCD feedback and user controls;
- guided serial test operation;
- real-time PC communication;
- automated extraction and storage of test data through a Python logger.

The project combined **instrumentation, embedded programming, calibration, serial communication and experimental testing** in a practical engineering tool.
